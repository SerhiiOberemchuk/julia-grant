# Зображення

| Файл | Де використовується |
|---|---|
| `julia-hero.jpg` | Hero (`Hero.tsx`) — погляд у камеру, усмішка |
| `julia-about.jpg` | «Про мене» (`About.tsx`) — за ноутбуком, у роботі |
| `julia/` | Оригінали фотосесії (запас: IMG_3887, IMG_3895 не використані) |
| `logo.jpg` | Оригінал логотипа; з нього вирізано `logo-mark*.png` та фавікони |
| `logo-mark.png` / `logo-mark-light.png` | Монограма «ЮЛ» для шапки (синя) і футера (світла) |
| `olx-image.webp` | Банер з OLX — ліва половина og-image (`assets/og-photo.jpg`) |

## Заміна фото

1. Вертикальний кадр, блоки кропають у **4:5** (`object-fit: cover`).
2. Покласти файл і оновити `src` у `Hero.tsx` / `About.tsx`.
3. За потреби підкоригувати кроп через `object-position` у відповідному module.css.

## Кейси

Скріншоти погоджених рішень класти в `public/cases/` і підключати в `site.cases.items`.
