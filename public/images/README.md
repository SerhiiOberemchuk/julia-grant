# Зображення

| Файл | Де використовується | Статус |
|---|---|---|
| `julia.jpg` | Hero (`Hero.tsx`) та «Про мене» (`About.tsx`) | **ТИМЧАСОВЕ стокове фото** — замінити на реальне фото Юлії |

## Заміна фото

1. Підготувати вертикальний кадр **4:5** (рекомендовано 1000×1250 px і більше), обличчя ближче до верхньої третини.
2. Зберегти як `public/images/julia.jpg` (та сама назва — код правити не треба).
3. За потреби підкоригувати кроп у блоці «Про мене»: `object-position` у `src/components/sections/About.module.css`.

Джерело поточного фото: Unsplash (безкоштовна ліцензія, дозволяє комерційне використання без зазначення авторства).
**Перед публікацією сайту стокове фото має бути замінене** — на лендінгу персонального бренду фото має бути реальним.
