## 2. Дизайн-концепція

**Метафора: «живий фінансовий документ».** Заявка на грант — це папір, цифри, чорнило й печатка «Погоджено». Сайт побудований на цих кодах, але подає їх тепло і по-людськи — як персональний бренд, а не як держустанова.

- **Палітра**: теплий крем-«папір» `#F5F1EA`, чорнило `#10151C`, лісовий зелений `#1E5A3C` (гроші, зростання, «погоджено»), м'ята `#CFEACF`, жовтий «текстовиділювач» `#F4E37C` для ключових цифр. Свідомо уникаємо корпоративного синього/золота конкурентів.
- **Типографіка**: **Unbounded** (заголовки — той самий характер, що сподобався замовниці) + **Manrope** (текст) + **JetBrains Mono** (мітки розділів «01 — Для кого», суми, «документні» підписи). Усі три з кирилицею, self-hosted через `next/font`.
- **Фірмові елементи**: кругла печатка «ПОГОДЖЕНО · ГРАНТ ОТРИМАНО» (SVG, анімація «удару» в hero), плаваючі «квитанції» погоджених заявок, міліметрова сітка на фоні hero, маркер під сумою, тонка паперова текстура (grain), нахилені «фото на столі», секції з великими скругленнями, що «накладаються».
- **Рух**: усе вручну — IntersectionObserver для появи блоків, лічильники, тікер-стрічка, слайдер калькулятора, акордеон на `grid-template-rows`. Поважає `prefers-reduced-motion`.
- **Mobile-first**: липка панель дій (дзвінок / Telegram / Записатися) з'являється після першого екрана і ховається біля форми; повноекранне меню; горизонтальні картки кейсів зі snap; таблиця порівняння перетворюється на картки.

## 4. Технічні рішення

- **Next.js 16 (App Router) + TypeScript**, CSS Modules + власні дизайн-токени в `globals.css`. Жодних UI-кітів, Tailwind, framer-motion тощо.
- Увесь контент — в одному файлі **`src/content/site.ts`** (тексти, цифри, контакти, FAQ), щоб правити без коду.
- Форма → `POST /api/lead`: валідація, honeypot, rate-limit, доставка в **Telegram** і/або **email (Resend)** — вмикається змінними оточення (`.env.example`). Без налаштування лід логується в консоль.
- **Google Ads**: `src/lib/analytics.ts` — при успішній заявці шле `conversion` (`NEXT_PUBLIC_GADS_CONVERSION`) + `generate_lead` + `dataLayer.push`. Залишилось лише додати тег gtag у layout, коли буде акаунт.
- SEO: metadata/OG, JSON-LD (ProfessionalService + FAQPage), семантика, `lang="uk"`, доступність (aria, фокус, reduced-motion).
- Сторінка `/privacy` — політика конфіденційності.

## 6. Наступні кроки

1. Отримати матеріали з чек-листа, підставити в `site.ts` та `public/`.
2. Підключити доставку заявок (Telegram-бот) і задеплоїти превʼю на Vercel.
3. Ревʼю з замовницею → правки текстів/акцентів.
4. Підключити домен, GA4/Google Ads тег і конверсію.
5. Опційно: лід-магніт (PDF-чек-лист «10 помилок у бізнес-плані») → секція перед FAQ.
